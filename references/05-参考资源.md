# 参考资源（GitHub 调研） · References

## Skill 格式

| 资源 | 用途 |
|---|---|
| [anthropics/skills](https://github.com/anthropics/skills) | 官方 skill 合集，`SKILL.md` + `references/` + `scripts/` 的写法范例 |
| [agentskills.io](https://agentskills.io) | Agent Skills 标准（frontmatter: `name` / `description`） |

要点：
- `SKILL.md` 只写"什么时候用 + 铁律 + 阶段闸门"，细节放 `references/`
- `description` 要写**触发场景**，不是功能清单
- 每个 reference 对应一个阶段，按需加载

## 可直接借鉴的 PCB skill

### [daishuge/pcb-skill](https://github.com/daishuge/pcb-skill) ★ 同路线

通过 **MCP 驱动 EasyEDA Pro**，从想法一路做到能下单的板。和本项目同一条技术路线。

可借用：
- `skills/pcb/references/03-jlc-manufacturing.md` —— 嘉立创几何/工艺限制完整清单
- `scripts/verify/gerber.py`、`mask_check.py`、`outline_check.py` —— **独立于 EDA** 复算 Gerber
- `references/02-review.md` —— 对抗式复核的方法论

不适用：它假设板子有电路、有 BOM、要贴片。纯美术板用不上第 2、4 阶段。

### [nasheed-x/pcb-skills](https://github.com/nasheed-x/pcb-skills)

面向 KiCad / Zener / ngspice 的功能板 skill，元件导入走 LCSC + easyeda2kicad。
**与美术板无关**，但其"元件库校验"的思路可以借。

## 差异化：和 `xxhhwtxx/pcb-art-keychain-skill` 有什么不同

同类里最接近的一个（2026-11-06 查：8 star / 2 fork / v2.1.0 / 仓库内**没有 LICENSE 文件**）。
它做的事和本 skill 高度重叠——参考图 → 装饰 PCB → 嘉立创 EDA 专业版。差别在**输入**和**落板方式**：

| 维度 | pcb-art-keychain-skill | gift-pcb（本仓库） |
|---|---|---|
| 输入 | 一张参考**图** | 一张参考图，或**一块参考板的 Gerber**（能逐层量数字） |
| 核心动作 | 本地分色 → 生成制造几何 | 解码参考板 → **抄数字**（金带 0.49 mm、孔组 8×φ0.305…）→ 回放纹路表 |
| 落板 | 产出 `create_in_eda.js`，用户手动在 EDA 里跑脚本 | CLI 直驱（`invoke --ext-uuid`）或直接写 `.epcb2` 文本 |
| 背景纹 | 按参数生成 | 从参考板 `--extract` 出 2 mm 朝向表按表回放，`13-check` 逐格比对 |
| 自检 | 本地检查 + 面积核算 | `13-check.py` 一张表（尺寸/金/线宽/丝印/哑黑/钻孔/织纹吻合度），FAIL 退出码 1 |
| 工艺侧重 | 彩阻焊 + 挂件、局部去毛刺、免费额度 | 哑黑 + 沉金 + 白丝印、校徽/纪念板、中文三行排版、3D 验收 |
| 许可 | 无 LICENSE 文件 | MIT |

值得直接借的三份（读了不亏）：

1. `references/manufacturing-finish.md` —— **「金色预览」≠ 已经选了沉金**：图案的铜 + 开窗只决定哪里露铜，
   下单时必须在「表面处理」里单独选 **ENIG 沉金**。本 skill 的下单说明也要照这句写。
2. `references/free-pcb.md` —— 嘉立创免费/优惠额度的核算口径。
3. `references/repair.md` —— 局部去毛刺：只在毛刺处打补丁，不整体腐蚀、不按面积删小装饰。

路线差异说清（免得用户以为只有一种）：它把「AI 不碰浏览器、不用登录」当卖点；
本 skill 走 CLI 直驱，省掉手动跑脚本这一步，代价是**本机必须装 EDA 专业版**并会 `session open`。
两条路都能下单，选哪条看用户手上有什么。
## 校徽素材：优先级从高到低

1. **学校官网的"校徽/标识"页**，通常能拿到 400–1000 px 的 PNG/SVG
2. **logo 聚合站**：`urongda.com/logos/<院校代码>` 这类站点常提供 1024 px 纯线条图
   （四川农业大学：`https://cdn.urongda.com/images/normal/medium/sichuan-agricultural-university-logo-1024px.png`，实测可用）
3. 维基百科 infobox 里的 logo（多为小尺寸 SVG）
4. 百度百科/小红书截图 —— **最差**，660 px 且带背景色，抠出来细节全丢，只能认出"大概是个花"

**不要用第 4 档开工。** 前几轮用 660 px 截图描出来的校徽被用户评价"你自己看这个校徽做的什么"：
叶片装饰环、底部建筑、书法体繁体环文全丢了。换成 1024 px 线条图后，整枚一次性描摹就对了。

判断标准：**源图上建筑窗格还能不能分辨**。能，这个尺寸就够；不能，再找更大的。

- [woojoo520/china-university-logos](https://github.com/woojoo520/china-university-logos) —— 部分院校 logo（PNG），条目不全

## 本项目里已经写好的工具（复用，别重写）

| 文件 | 用途 |
|---|---|
| `scripts/mockup.py`、`layouts.py`、`front_opts.py` | Pillow 版式 mock |
| `scripts/emblem_*.py`、`badge*.py` | 徽记描摹/重构、间隙实测 |
| `scripts/hand_*.py`、`gen_*.py` | 手写体与字形 → 扫描线矩形（生成 EDA 直吃的 JS） |
| `preview/v7`、`preview/v10` | 历次生成的矩形块 JS（可直接复用坐标） |

Gerber 复核用的是临时脚本（`gr2.py` 光栅化 + `comp6.py` 逐层合成），
两个都是几十行，比引第三方库快：解析 `G36/G37` region、`D03` flash、`G02/G03` 圆弧即可。
