# 参考板解码 · Decoding a Reference Board

> 本篇只讲**怎么读层**：哪一层是什么、看到什么想到什么、常见误判。
> 「从参考板抄哪些元素、各抄多少」是另一件事，见 `07-从参考板抄什么.md`。

## 为什么要逐层

一块成品板在眼里是"黑底金字"。但在文件里它是四层叠加：

| 层 | 含义 | 视觉结果 |
|---|---|---|
| GTL / GBL | 铜 | 被阻焊盖住 → **黑**（只有极细微的浮雕反光） |
| GTS / GBS | 阻焊开窗 | 露出铜 → **金**（沉金） |
| GTO / GBO | 丝印 | **白** |
| GKO | 板框 | icut |
| *.DRL | 钻孔 | 洞 |

**关键结论：金色 = 铜 + 开窗，两者缺一不可。** 只看 GTL 会把整块板都想成金的。

## 解码清单（逐条打勾）

1. 板框长宽、是否异形、圆角半径
2. 铜层：纹理密度（线宽/线距/覆盖率）、大铜面、图形
3. **开窗层：一共几个区域？每个区域是什么？**（边框？图形？焊盘？装饰件？）
4. 丝印：文字内容、字号、位置
5. 钻带：孔径分布、孔位（是否有挂绳孔）
6. 特殊件：芯片装饰、日期、落款、工厂水印

## 实测样例（Hello Kitty 参考板，86 × 54 mm）

- GTL：13 344 个多边形，编织纹，71.6% 铜，等效线宽 0.117 mm
- **GTS：只有 4 个区域** → 一圈细边框 + Kitty 线稿；其余铜全被阻焊盖住
- GTO：3 行白丝印（粗体标题 / 手写体英文 / 极小署名）
- GBO：9 个大字 + 落款 + **`JLCJLCJLCJLC`（嘉立创水印，不是设计）**
- GBS：48 个区域 → **金色芯片图形 + 日期重复两遍 + 右上角小字**
- DRL：17 个孔，其中 9 个 φ3.0 挤在右上角

如果只报"GTS 有 4 个区域"而不去看它们长什么样，就会漏掉边框。

## 常见误判

- 把 `JLCJLCJLCJLC` 当成设计师署名或日期
- 把 GTL 的编织纹当成金色（其实它是黑的浮雕）
- 忽略钻带，漏掉孔
- 用包围盒代替内容：bbox 只告诉你"有多大"，不告诉你"是什么"
