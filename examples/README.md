# examples

只放**一块**完整样例：`uestc70/`。

## 为什么只有一块

样例的作用是「证明这套流程真的能产出一块能下单的板」，不是「作品集」。
多放几块只会让仓库变大、让测试变慢，还容易让读者以为某个尺寸/配色是默认值。

一块板里已经包含了全部要素：异形圆角板框、贴边金带、圆盘型徽记、汉字扫描线、
笔画字体英文、双面织纹、主孔 + 一圈小孔、正背镜像。

## 加新样例的门槛

新样例必须**同时**带上这些东西，否则不如不加：

| 必须 | 为什么 |
|---|---|
| `spec.json`（徽记图用相对路径） | 别人能照着重建，而不是只能看图 |
| `gerber.zip`（导出的原始包） | `13-check` 和 `tests` 要拿它当金板 |
| `验收单.md`（`13-check --md` 出的） | 数字有出处，不是"我看过了" |
| `preview/` 三张：3D 正、3D 背、徽记或织纹 ≥60 px/mm | 合成图看不出 0.06 mm 的缺陷 |
| README 里写清「这块板哪一步必须 EDA」 | 不然 clone 下来的人会卡在导出 |
| 在 `tests/` 里加一条金板断言 | 否则它就不是样例，只是一张图 |
