## 所以本仓库这么做

1. **只放这一张**：不再放学校其他标识、不放到 `assets/`（首图区）、不用它做仓库名/描述/topics；
2. **明确声明不在 MIT 内**：`LICENSE` 只覆盖我写的代码与文档；本文件的版权归学校；
3. **非商业、可移除**：仅作「一块 86×54、哑黑+沉金、双面织纹的纪念板长什么样」的技术示例；
4. **不宣称授权**：读到这里的你，如果要把这块板用于**商业目的**（售卖、随商品赠送、企业宣传），

## 想删掉它？（30 秒）

```bash
# 1. 用任何一张 PNG 顶替（同一尺寸最佳；圆盘型徽记要求：实心盘 + 挖空字）
cp 你自己的徽记.png examples/uestc70/badge.png
# 2. 重跑测试：徽记换了，金板数字会变，测试会告诉你差多少
python -m pytest tests -q
```

如果只想**不发布**徽记：删掉 `examples/uestc70/badge.png` 后，`test_rebuild` 会自动 skip
（它会提示"缺徽记源图"），其余测试照常跑。spec 里那一行 `badge.png` 保持不变即可。
